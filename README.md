# Timer

A personal interval timer (PWA) for Android. Unlike classic Tabata timers, a
workout is a list of **blocks**, each with its own **steps** and **repeat count** —
so "1:00 work → 2:00 work → 0:05 rest, × 5" is easy.

- Big full-color current step, next step below, total time left on top
- Soft bell tones: pips at 3-2-1, rising chime for work, falling chime for rest
- Vibration on every transition, screen kept awake while running
- Works offline; workouts are stored on the device

## Install on Android
1. Enable GitHub Pages for this repo (Settings → Pages → Deploy from branch `main`, `/root`).
2. Open the Pages URL in Chrome on the phone.
3. Menu ⋮ → **Add to Home screen** / **Install app**.

No build step — it's plain HTML/JS in `index.html`.
